Patch Tuesday Brief

November 2026 Security Updates

What Microsoft and Adobe actually released on November 10, the handful of fixes that matter, and what the updates are known to break.

Microsoft's release carries 1,094 CVEs by our count from the Security Update Guide; the Zero Day Initiative counted about 1,090 in its November 2026 review of the same release. Either way, it is the second month in a row above every previous year.

The ones that matter

Out of 1,094 Microsoft fixes, these are the ones a small business or its IT provider should care about this month, worst first.

CVE-2026-124194CVSS 6.5

Microsoft Outlook flaw, already being exploited

The score looks modest, but this is the one bug attackers are using right now. A booby trapped message file makes Outlook quietly connect to an attacker controlled location and hand over a credential hash, which the attacker can then use to log in as that user. CISA added it to the Known Exploited Vulnerabilities catalog on release day and gave federal agencies until November 24, 2026 to patch.

What to do: push the November Office and Outlook updates first, ahead of everything else this month.

CVE-2026-116928CVSS 9.8

Windows Search flaw reached through Exchange mail

An attacker emails a specially crafted attachment, the mail server indexes it automatically, and code runs on the server. Nobody has to open anything. It is the most severe server bug this month, worse than the fixes written specifically for Exchange.

What to do: if you run your own Exchange server, patch it this week, not at month end.

CVE-2026-119958

Windows LDAP flaw, dangerous on domain controllers

An unauthenticated attacker can send crafted LDAP calls over the network and run code in the LDAP service, with no user interaction. On a domain controller, the server that decides who can log in to everything, that is about as bad as it gets.

What to do: domain controllers go near the top of the patch order, right after the Outlook fix.

CVE-2026-118207

Exchange Server remote code execution

One of nine Exchange fixes this month, rated Critical, delivered in update KB5133453. On premises Exchange is a favorite attacker target because it faces the internet and holds every mailbox.

What to do: patch Exchange this week. If web mail or mail flow has been flaky since the October updates, check the breakage section below.

CVE-2026-96092

Windows DNS Server flaw on Server 2025

Part of a small set of DNS fixes this month that researchers class as wormable: unauthenticated, over the network, no user interaction. DNS servers are easy to forget because they just sit there working.

What to do: include your DNS servers in the first patch wave, especially Server 2025.

CVE-2026-119952

Windows Schannel flaw, exploitation rated more likely

Schannel is the part of Windows that handles secure connections. Microsoft rates this one Exploitation More Likely, one of only a few Critical fixes carrying that label this month, even though the attack is rated complex.

What to do: it rides in the normal Windows cumulative update, so no special handling, just do not defer the November updates.

Update breakage watch

What recent updates are known to break, checked daily against Microsoft's release health pages and credible admin reports. Confirmed items only, with the workaround where one exists.

November update KB5132061 can fail to install

Affects: Windows 11 24H2, 25H2, and 26H2 after KB5132061. Install fails with 0x800f0993, 0x800f0989, or 0x80070306. Microsoft confirmed it as a known issue on November 11. Only machines that installed the October preview KB5127936 are affected. An automatic repair is rolling out through Windows Update, expected done by Friday morning, November 13, with no user action needed, and the update then installs automatically.

What to do: if the install fails, wait for the automatic repair. If it still fails after 48 hours, contact Microsoft Support. DISM or a manual .msu download are reported as alternates.

November updates crash Sage 50 US when opening a transaction window

Affects: Sage 50 US 2026 and 2021 on Windows 10 and Windows 11 after KB5132061 (Win 11), KB5132059 (Win 11 26H1), or KB5131096 (Win 10). Sage confirmed it on their Community Hub: the app crashes when opening a transaction window after the November update, and removing the update fixes it. They are investigating with Microsoft. For hosted Sage 50, removing the update may not fix it; Sage support told a hosted user to wait for a Sage and Microsoft fix. Some users also report the update reinstalling itself after removal, so pause updates after uninstalling.

What to do: hold the November update on Sage machines, or uninstall it temporarily if it already crashed, then pause updates. Hosted Sage 50 users should wait for the Sage and Microsoft fix.

Activation commands fail after the November updates

Affects: Windows 11 23H2 after KB5131087, Windows 10 after KB5131096, Windows Server 2025 after KB5131080, Windows Server 2022 after KB5131090, and Windows Server 2019 and Windows 10 LTSC 2019 after KB5131085. The activation commands slmgr.vbs /skms-domain and /ipk fail with error 0x80041008. Machines that are already activated stay activated.

What to do: there is no workaround yet except contacting Microsoft Support for Business. Microsoft expects a resolution in the coming days. Do not re-image or re-activate machines in bulk until it lands.

SQL Server linked server connections may stay open

Affects: SQL Server on server devices after the October 13, 2026 updates and later updates. Linked server queries to external databases, with Oracle and PostgreSQL named, may leave connections open instead of closing them.

What to do: a mitigation is available through Microsoft Support for Business, and an out-of-band update is expected in the next few days. Deploy with this in mind if you run SQL Server linked servers.

October updates can break office Wi-Fi and wired network logins

Affects: Windows 11 24H2, 25H2, and 26H2 after KB5127648. The October update turned on a stricter sign in rule (NTLMv1 enforcement). Networks that log users in with the older MS-CHAPv2 method, common for office Wi-Fi, can start refusing connections. Home Wi-Fi with a plain password is not affected. Microsoft confirms the change is intentional hardening, so no fix is coming.

What to do: if office Wi-Fi breaks after the October update, your IT provider can roll the setting back to audit mode, or better, move the network to certificate based sign in (EAP-TLS).

October Server updates can stall on premises Exchange

Affects: Exchange 2016, 2019, and Subscription Edition on Server 2016 to 2025 after the October 13 updates. Sign ins to web mail can fail, mail can sit in the Outbox, and mailbox database copies can stall, starting about a day after a restart. Microsoft confirms the cause: a new limit on a lookup service Exchange leans on.

What to do: fixed in the November Server updates. The registry workaround is no longer needed once those are installed.

Some USB audio devices stopped working after the September and October updates

Affects: USB Audio Class 1.0 devices (some headsets, docks, and conference gear) on Windows 10, Windows 11, and Server. The device fails to start and shows error Code 10.

What to do: fixed in KB5132061 and KB5131096. Install the November update; the 2 channel mode workaround is no longer needed.

Always On VPN connection bug: fix is in the November updates

Affects: Always On VPN on Windows 11 24H2 and later, broken by the September updates and stuck on Connecting.

What to do: fixed on all branches in KB5132061. Install the November update, then the single protocol pinning workaround can be reverted.

Fixed in the November cumulative: Smart App Control and Remote Desktop

Affects: Smart App Control toggle grayed out, fixed for 24H2 in KB5132061; Remote Desktop failures for non-admin users (0xC000000D), fixed in KB5132061.

What to do: install the November update. No workaround needed after that.

Watch item, not confirmed breakage: KB5132061 tightens PowerShell script signature validation, so signed scripts with invalid UTF-8 may now fail validation. The November cycle now has four confirmed breakage issues above.

Worth knowing

Notable fixes and campaigns that sit outside the exploited list but can still bite a small shop.

CVE-2026-83844

Microsoft Paint flaw with a patching gotcha

A serious flaw in the Paint app bundled with Windows, disclosed October 13. It is not being exploited and CISA has not listed it, but the fix only ships through the Microsoft Store, never through Windows Update. Shops that block the Store, or never open it, will stay unpatched without noticing.

What to do: make sure Store apps are set to update, or push the Paint update through your management tool.

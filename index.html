November 2026 Patch Tuesday · Released Nov 10

November Patch Tuesday: 1,093 fixes, 63 of them Critical, and 1 exploited zero-day

The exploited flaw is in Microsoft Outlook, and attackers are already using it in the wild. The release also patches critical flaws in Exchange Server and SharePoint Server. Next Patch Tuesday is December 8, 2026.

CVE-2026-124194CVSS 6.5

Microsoft Outlook zero-day · already exploited

This Microsoft Outlook flaw is already exploited in the wild, which makes it the first fix to apply from the November release. CISA gave federal agencies until November 24, 2026 to fix it. Treat that as your deadline too.

CVE-2026-118207CVSS 8.8

Exchange Server remote code execution · Critical

A critical remote code execution flaw in Exchange Server, CVE-2026-118207 (CVSS 8.8). The same release also fixes a SharePoint Server privilege escalation, CVE-2026-120002 (CVSS 9.9). If you run Exchange or SharePoint on premises, patch both in this cycle.

What to do: install the November Windows updates on every PC and server now, don't wait for the weekend. If you use an IT provider, ask them to confirm the November cumulative update is deployed across your machines, and that Outlook, Exchange Server, and SharePoint Server are covered.

Due dates are the deadlines CISA sets for US federal agencies. Nobody fines your business for missing one. PatchWatch uses them as an urgency yardstick for everyone: if the government has to fix it by Friday, it shouldn't sit in your queue for a month.

Who should care about what

  • Plex: anyone running a Plex media server at home or at the office.
  • BeyondTrust: businesses whose IT provider uses it to remote into their machines for support.
  • Atlassian: teams using Confluence or Jira.
  • Cisco Secure Email Gateway: businesses whose email is filtered through Cisco.
  • Ahsay: businesses backing up their data with Ahsay.

End-of-life watch

Software that has stopped, or is about to stop, getting security patches. Unsupported software doesn't break on day one; it just gets easier to attack every month after.

Windows Server 2012 and 2012 R2

Support ended Oct 10, 2023

Ended

Fully out of support now. The paid Extended Security Updates that kept these patched also ended Oct 13, 2026.

Windows 10 (version 22H2)

Support ended Oct 14, 2025

Ended

No more security patches. Still common in small offices. Plan the move to Windows 11.

Microsoft Office 2016 and 2019

Support ended Oct 14, 2025

Ended

No more security patches for Word, Excel, and Outlook from these generations.

Exchange Server 2016 and 2019

Support ended Oct 14, 2025

Ended

No more security patches. The supported paths are Exchange Server Subscription Edition or Exchange Online.

SQL Server 2016

Support ended July 14, 2026

Ended

No more routine security patches. Upgrade SQL Server in the same project as any server move, or buy Extended Security Updates as a bridge.

Windows 11, version 24H2 (Home/Pro)

Support ended Oct 13, 2026

Just ended

Just ended. Update to version 25H2 to stay covered.

Microsoft Office 2021

Support ended Oct 13, 2026

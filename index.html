Patch this first

The one update that matters most right now, and why.

October 2026 Patch Tuesday · Released Oct 13

Microsoft's biggest update release ever: 1,413 fixes, about 78 of them Critical

Two of those fixes stand out. One flaw is already being used by attackers. Another was publicly disclosed before the fix shipped, which means attackers knew about it first.

CVE-2026-96951CVSS 8.8

Windows Shell: "Mark of the Web" bypass · already exploited

Windows normally warns you before opening a file downloaded from the internet. This flaw strips that warning away, so a booby-trapped download can open silently. CISA gave federal agencies until October 16 to fix it. Treat that as your deadline too.

CVE-2026-108398CVSS 8.8

.NET / Windows Defender Application Control bypass · publicly disclosed

Application Control is the Windows feature that only lets approved programs run. This flaw lets an attacker get around it, so unapproved software can slip past a control many businesses rely on to keep PCs locked down.

What to do: install the October Windows updates on every PC and server now, don't wait for the weekend. If you use an IT provider, ask them to confirm the October cumulative update is deployed across your machines.

Due dates are the deadlines CISA sets for US federal agencies. Nobody fines your business for missing one. PatchWatch uses them as an urgency yardstick for everyone: if the government has to fix it by Friday, it shouldn't sit in your queue for a month.

Who should care about what

  • Plex: anyone running a Plex media server at home or at the office.
  • BeyondTrust: businesses whose IT provider uses it to remote into their machines for support.
  • Atlassian: teams using Confluence or Jira.
  • Cisco Secure Email Gateway: businesses whose email is filtered through Cisco.
  • Ahsay: businesses backing up their data with Ahsay.
